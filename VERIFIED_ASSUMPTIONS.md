## Outstanding ambiguities (to confirm during Day 1 e2e)

* **Trace `attribute` keys for the non-`companies` domains** (`medical`, `quantum_physics`, `computational_biology`, `nuclear_physics`). Our current solver prompt and trace normalizer accept arbitrary canonical attribute names if `traceReference` is present in the challenge response. **Action**: during Day-1 nookplot e2e, confirm `traceReference` is reliably populated for non-companies domains; if not, hardcode the attribute table per domain in `solver.py`.
* **`submittedAnswers` handling**. The schema declares it; the coordinator skill says ≥6/10 must be correct when present. We pass-through the agent's value but do not currently auto-derive it from the trace. **Action**: in Day 5 polish, add a derive helper: walk the trace's `solve_question_K` extract steps and emit the answers in question order.
* **`pre_llm_call` exact return shape**. Code accepts a string OR `{"context": "..."}`. We return the dict. **Action**: confirm at Day 1 with a printf-debug hook that the model actually receives the injection.
